# CLOUDSTACK PRO PRICING SECTION

This project is a responsive SaaS pricing section designed for a fictional product called CloudStack Pro. It is inspired by modern SaaS platforms like CineFlow and focuses on clean UI, responsiveness, and conversion-friendly design.

---

## Overview

CloudStack Pro Pricing Section is a frontend UI project built using HTML and Tailwind CSS.  
It is designed to display pricing plans in a structured and visually clear way.

The layout demonstrates how SaaS companies present:
- Pricing tiers
- Feature comparison
- Highlighted “Most Popular” plan
- Call-to-action buttons

---

## Project Inspiration

This project was inspired by the CineFlow Portal onboarding system, which focuses on:
- Clean UI design
- User-friendly layout
- Structured information flow
- Responsive web design



---

## Key Features

### Responsive Layout
- Mobile: Cards stack vertically (1 column)
- Desktop: Cards display in a 3-column grid

---

### Modern SaaS Design
- Clean pricing cards
- Highlighted middle “Pro” plan
- Smooth hover animations
- Rounded corners and soft shadows

---

### Pricing Structure
The section includes three pricing tiers:
- Starter Plan
- Pro Plan (Most Popular)
- Enterprise Plan

---

### UI Enhancements
- Hover lift effect on cards
- Highlighted border ring for featured plan
- Clear typography hierarchy for pricing
- Consistent spacing using Tailwind utility classes

---

## Technologies Used

- HTML5
- Tailwind CSS - CDN
- Responsive grid system
- Utility-first styling approach
